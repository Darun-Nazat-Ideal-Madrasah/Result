দারুন নাজাত আইডিয়াল মাদ্রাসা — সম্পূর্ণ নতুন অনলাইন ফলাফল ওয়েবসাইট

ফোল্ডার:
- index.html — মূল ওয়েবসাইট
- style.css — ডিজাইন
- script.js — ফলাফল অনুসন্ধানের কার্যক্রম
- assets/header.png — ওয়েবসাইটের হেডার/ব্যানার
- data/results-2026.json — ২০২৬ সালের ফলাফল
- README.txt — নির্দেশনা

সার্চের ক্রম:
সাল → পরীক্ষা → শ্রেণি → রোল নম্বর → ফলাফল দেখুন

নাম দিয়ে সার্চ রাখা হয়নি।

২০২৬ সালের প্রস্তুতকৃত দ্বিতীয় সাময়িক পরীক্ষার ফলাফল অন্তর্ভুক্ত আছে।
ZIP Extract করে পুরো ফোল্ডারটি Netlify বা GitHub-এ আপলোড/Deploy করুন।
